PARA MINHA NENÉM ♡ — VERSÃO PARA GITHUB PAGES

ESTRUTURA
Todos os arquivos estão na mesma pasta:
- index.html: página principal
- style.css: estilos
- script.js: interações
- 1.jpg até 10.jpg: fotografias do mural

COMO PUBLICAR NO GITHUB
1. Extraia este ZIP no computador.
2. Abra o repositório do seu site no GitHub.
3. Clique em Add file > Upload files.
4. Selecione todos os arquivos desta pasta (incluindo index.html, style.css, script.js e as 10 fotos) e arraste para a área de envio.
5. Faça o commit das alterações.
6. Em Settings > Pages, configure a publicação pela branch principal (geralmente main) e pela pasta /(root), se ainda não estiver ativada.

IMPORTANTE
- Não envie o ZIP fechado ao repositório esperando que o site seja publicado. Extraia primeiro e envie os arquivos que estão dentro dele.
- O index.html já foi atualizado para localizar style.css, script.js e as fotos diretamente na mesma pasta.
- As fontes decorativas são carregadas do Google Fonts quando há internet.

PERSONALIZAÇÃO
